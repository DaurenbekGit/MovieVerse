# MovieVerse — Frontend Assignment 4

## Project Description

MovieVerse is a movie website developed using HTML, CSS, and JavaScript.

In Assignment 4, we improved our previous website by adding interactive JavaScript features. The main goal was to make the website more functional and user-friendly.

We kept the original website design and implemented five JavaScript tasks.

## Assignment 4 Tasks

### Task 1 — Form Validation

We implemented form validation using JavaScript.

The subscription form checks the following conditions:

- Email must have a valid format.
- Password must contain at least 8 characters.
- Confirm password must match the password.
- Required fields cannot be empty.
- Error messages appear when the entered information is incorrect.

If all inputs are valid, the website displays a success message.

### Task 2 — FAQ Accordion

We added an interactive FAQ accordion to the movie page.

Users can click on a question to display its answer. Clicking the same question again hides the answer.

JavaScript handles the click events, while CSS provides smooth transitions.

### Task 3 — Popup Subscription Form

We added a subscription popup to the profile page.

When the user clicks the "Subscribe Now" button, a popup form appears.

The popup can be closed by:

- Clicking the close button.
- Clicking outside the popup.
- Pressing the Escape key.

The form is hidden by default.

### Task 4 — Background Color Changer

We implemented a button that changes the background color of the website.

Each click switches to the next predefined color.

The available colors include dark, white, gray, and Nordic-inspired shades.

This functionality is implemented using JavaScript and DOM manipulation.
